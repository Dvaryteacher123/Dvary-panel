# 🤖 BotHost Panel

Hosting panel kamili ya kuuza na kudeploy seva za bot (WhatsApp, Telegram, Discord, n.k.)
kwa kutumia mfumo wa **Sarafu (Coins/RAM)** — imeunganishwa moja kwa moja na
**Pterodactyl Application API**.

---

## ✨ Vipengele

- 🔐 Usajili, kuingia, na usimamizi wa watumiaji (bcrypt + sessions)
- 💰 Mfumo kamili wa Coins (credit/debit + historia ya transactions)
- 🚀 Deploy bot mpya kwa sekunde kwa Pterodactyl API
- 💾 Nunua RAM ya ziada au Disk kwa seva iliyopo
- ⚡ Power controls (start, restart, stop, kill) + auto status polling
- 🔑 Onyesho la panel credentials (username/password)
- 👑 Admin panel kamili:
  - Dashibodi ya takwimu (users, panels, RAM, coins)
  - Kuongeza/punguza coins kwa mtumiaji
  - Ban/unban, promote/demote admin
  - Kuona **idadi ya panels kwa kila mtumiaji**
  - Kusimamisha/kufuta seva yoyote
  - Broadcast coins kwa watumiaji wote
- 🎨 Rangi nyekundu ya kutisha (Red Horror Theme)
- 📱 Responsive design (mobile-friendly)
